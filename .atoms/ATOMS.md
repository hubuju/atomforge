# Project Context

## Project Overview

**AtomForge —— 一个可运行的 Atoms Demo**。对话驱动的 AI 应用生成工作台：注册登录 → 项目列表 → 三栏工作台（对话 / 代码 / 实时预览）→ 多轮迭代 → 版本回滚 → AI 自动修错 → 一键发布公开链接。全部数据持久化到 Atoms Cloud 数据库，AI 生成走 claude-opus-5 流式输出。

## Constraints

- 设计 register：**Product**（工具型工作台），基准 Linear / Vercel / Raycast。
- **深浅双主题可切换**：顶栏与设置面板均可切换「浅色 / 深色 / 跟随系统」，偏好写入 localStorage（`atomforge.theme`），首屏在 React 挂载前上色，避免闪白。深色为未设置时的默认表现（跟随系统且系统为深色时）。
- 主题实现只允许走 CSS 变量：`:root` 为浅色令牌、`.dark` 为深色令牌；状态色与代码高亮同样走 `--tone-*` / `--ink-*` / `--code-*` 变量，组件里禁止再写死 `text-emerald-300`、`bg-[hsl(...)]` 这类单主题颜色。
- 配色：中性色统一 tint 向 hue 82，饱和度 4-8%；`--background` hsl(80 6% 7%)；`--primary` hsl(82 70% 56%) 酸性青柠；强调色占比 ≤10%。禁用渐变文字、玻璃拟态、霓虹绿黑、纯黑纯白面板。
- 字体：标题 `Sora`，正文 `Manrope`，代码 `JetBrains Mono`（均经 Google Fonts 引入，避开 reflex-reject 清单）。
- 动效：150-250ms，`cubic-bezier(0.25, 1, 0.5, 1)`；只表达状态变化，无装饰性动画。
- 数字/版本号使用 `tabular-nums`。
- 顶栏只显示头像图标，不暴露用户邮箱/ID。
- 不得修改 `index.html`、`src/pages/AuthCallback.tsx`、`backend/core|models|main.py`。
- 需要生成的图片（4 张）：品牌 Logo 图标、落地页 hero 视觉、工作台流程示意图、能力卡片配图。
